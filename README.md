# Yaya

一只住在 macOS 菜单栏和桌面上的猫。点它会展开一个环形菜单，把截图、录屏、标注、文字识别和常用图片处理放在同一个入口里。

> 界面语言为中文。最低要求 **macOS 15 (Sequoia)**。

## 它做什么

| 能力 | 说明 |
|---|---|
| **区域截图** | 拖拽框选，松手即出图；自动复制到剪贴板 |
| **窗口截图** | 从窗口列表里点选，浮层可拖动，点外部取消 |
| **全屏截图** | 一键整屏，支持多显示器 |
| **标注** | 截图后原地贴回选区，工具条可画矩形、箭头、文字、马赛克、编号；浮层可整体搬走（按住空格拖动） |
| **录屏** | 框选后选区**可调整大小**，确认后 3-2-1 倒计时开录；停止后投递一条静默系统通知 |
| **文字识别** | 框选区域识别文字，结果面板可直接编辑、复制，面板可拖动 |
| **图片处理** | 转 PNG / JPEG / HEIC、压缩、缩小一半、旋转 90°、复制路径、在访达中显示 |

所有采集都按屏幕的 **backingScaleFactor** 输出，Retina 上得到的是 2x 真像素，并把 144 DPI 写进 PNG，避免查看器把 2x 图当 1x 放大显示。

## 系统要求

- macOS 15.0 及以上
- Apple Silicon 或 Intel 均可

## 自己构建

项目是 Swift Package，没有 `.xcodeproj`，用脚本组装 app 包。

```bash
git clone <仓库地址> yaya
cd yaya
./build.sh
```

脚本会做四件事：编译、从 `icon.iconset` 生成 `AppIcon.icns`、组装 `Yaya.app`、用 **ad-hoc 签名**（不需要开发者账号）。

构建完把 `Yaya.app` 拖进「应用程序」文件夹，然后打开。

## 首次运行必做

Yaya 的截图和录屏依赖系统的「屏幕录制」权限，第一次必须手动授予：

1. 打开「系统设置 → 隐私与安全性 → 屏幕录制」
2. 勾选 **Yaya**
3. 完全退出 Yaya 再重新打开

**注意**：该权限绑定代码签名。每次重新编译、重新签名，系统会认为是新应用，需要重新勾选一次。这是 macOS 的机制，不是程序的缺陷。

## 快捷键

全局快捷键可在「设置」里自行录制修改，默认值见设置窗口。

> 建议避开与系统截图（⇧⌘4 / ⇧⌘5）冲突的组合。

## 项目结构

```
Sources/SwivelX/
├── AppDelegate.swift       菜单栏、宠物、流程编排
├── CaptureEngine.swift     截图 / 录屏 / 像素比换算
├── RegionSelector.swift    选框浮层（可调整大小、8 个手柄）
├── Annotate.swift          标注浮层与画布
├── OCR.swift / OCRPanel    文字识别与结果面板
├── OrbitMenuView.swift     环形菜单
├── PetView.swift           桌面宠物
├── SystemNotifier.swift    静默系统通知
├── Motion.swift            缓动 / 弹簧 / 关键帧
└── ...
packaging/Info.plist        app 包模板
build.sh                    构建脚本
```

## 已知限制

- 界面仅中文
